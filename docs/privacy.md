# CopyPolish 隐私说明

> 本文档面向用户与审计者，说明 CopyPolish 桌面版如何处理本地数据。  
> 当前版本：`0.6.2-dev.1`，最后更新：2026-09-06。

## 0. v0.6.2 隐私维护范围

v0.6.2 仅进行隐私和安全维护，不增加新的用户功能。维护重点是确保正文默认不落盘、设置备份与临时文件不残留正文、测试 artifact 不包含正文或本地路径，并在完成审计前冻结 v0.7.0 功能开发。

## 1. 设计原则

CopyPolish 的文本处理**全部在本地完成**。正式桌面版的生产构建中：

- **不发起任何外部网络请求**（生产 CSP 仅允许 `'self'` 与 `tauri:` 源）；
- **不包含遥测、分析、广告或崩溃自动上传**；
- **剪贴板写入只在用户显式操作时发生**（点击"复制结果"或"复制并清空"）；
- **设置文件保存在用户本地**，不会自动上传或同步到任何服务器。

## 2. 本会话默认关闭的功能

### 2.1 启动时恢复上次输入（默认关闭）

> 设置项：`启动时恢复上次输入`（`restore_last_input`）

**默认行为**：应用**不会**把上次编辑的正文保存到磁盘；重启后输入框为空。

仅在用户**显式开启**该开关后，应用退出时才会把当前输入框正文保存到本地设置文件（`rules.yaml`），并在下次启动时恢复。

开启该功能意味着：

- 正文将以**明文**保存在设置文件中；
- 关闭开关会立即触发一次保存，**清空**已保存的正文；
- 用户可随时点击"**清除已保存正文**"按钮，立即删除磁盘中的副本。

### 2.2 浏览器演示模式的本地存储

浏览器 fallback 版（非 Tauri 桌面版）使用 `localStorage` 保存演示设置：

- 默认**不保存**正文；
- 使用独立、带版本的 storage key；
- 页面内提供"**清除演示数据**"按钮；
- 生产 Tauri 模式**不会**读取演示模式的 `localStorage`。

## 3. 本地数据清单

| 数据 | 位置 | 是否默认写入 | 说明 |
|---|---|---|---|
| 启用的规则 key 列表 | `rules.yaml` | 是 | 不含用户正文 |
| 主题 / 字体 / 缩放 | `rules.yaml` | 是 | UI 偏好 |
| 自定义替换 | `rules.yaml` | 是 | 字面量替换条目 |
| 简繁转换模式 | `rules.yaml` | 是 | `none` / `t2s` / `s2t` |
| 快捷键绑定 | `rules.yaml` | 是 | 用户自定义绑定 |
| **上次输入正文** | `rules.yaml` | **否**（默认关闭） | 需显式开启"恢复上次输入" |
| 浏览器演示设置 | `localStorage` | 是（仅浏览器版） | 独立 key，可随时清除 |

## 4. 如何彻底清除本地数据

1. **关闭"启动时恢复上次输入"**：已保存的正文会在下次保存时被清空；
2. **点击"清除已保存正文"**：立即从设置文件中删除正文；
3. **删除设置文件**：删除应用目录下的 `rules.yaml`；
4. **浏览器演示模式**：点击"清除演示数据"或清除浏览器本地存储。

## 5. 测试 artifact 与诊断数据

- E2E 测试产生的 artifact（截图、日志）仅用于 CI 调试，**不属于生产功能**；
- 测试脚本不会收集或上传用户的真实文本内容；
- Release 构建中**不包含**测试插件或诊断接口。
- v0.6.2 维护验收会额外扫描测试 artifact、日志和临时设置，确认不存在真实正文、用户目录、凭据或剪贴板内容。
- Unix 平台的 `rules.yaml` 与备份文件使用用户私有权限；保存失败时会清理临时文件。

## 6. 第三方依赖与供应链

- 生产构建使用 Tauri 2 + React 19 + Rust，不引入任何外部 CDN 或远程字体；
- 依赖更新通过 Dependabot / Renovate 提示，由维护者人工审阅后合并；
- 漏洞处理策略见 [security.md](security.md) 与 `.github/dependabot.yml`。
