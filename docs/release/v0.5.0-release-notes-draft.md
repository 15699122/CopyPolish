## 主要更新

- 排版引擎迁移为可扩展的原生 Rust 架构，移除 Python/PyO3 运行时依赖。
- 规则改由统一注册表管理，当前内置 13 条规则，并使用稳定英文 key。
- 明确区分 `All`、`Defaults`、`Only`、`None` 四种规则选择模式，修复“全不选”语义歧义。
- 新增有限词典和保守语法识别，支持 Unicode、SI、温标及复合科学单位。
- 增加数学表达式识别与保护，例如 `∂f/∂x`、`x≤y`、`a≈b`、`3±0.5` 和 `2×3`。
- 引入 grapheme cluster 边界处理，保护 emoji ZWJ、组合附加符和 CJK Extension B 字符。
- 扩展 Markdown、HTML、URL、邮箱和 LaTeX 保护范围，包括 front matter、代码块、任意长度反引号、嵌套链接、HTML block、表格分隔行、转义标记、硬换行和美元数学。
- 增强化学式保护，支持 `Fe²⁺`、`SO₄²⁻`、`FeCl₂·4H₂O` 等片段。
- 引入统一 span 模型、优先级仲裁和 UTF-8 安全 TextEdit 基础设施；span-aware 混合管线已接管生产格式化入口。
- 设置窗口支持主题、界面字体、编辑器字号和主界面缩放，并显示保存/恢复状态。
- 用户设置改为 `rules.yaml`，支持旧 JSON 迁移、稳定 key 迁移、原子写入、备份和损坏恢复。
- 快捷键支持总开关、自定义绑定、冲突校验、系统高风险组合键拒绝和 IME 防护。
- 新增实验性 Ratatui TUI，支持多行编辑、共享规则设置、OSC 52 剪贴板、stdin/stdout 和文件输入输出。
- 增加数据驱动黄金样例、复杂组合、规则交互、Unicode、换行、幂等性和结构优先级回归测试。
- GitLab Build Service 支持 Linux/Windows 跨平台构建、资产汇总、SHA256 校验和内部 Release。
- 增加本地发布构建与资产校验脚本，以及 SOPS/age 凭据管理和恢复文档。

## 界面与交互改进

- 输入区和输出区高度、行间距统一。
- 小窗口下双栏布局自动堆叠。
- 主窗口最小尺寸为 `800 × 600`。
- 输入框提供更明确的占位提示，输出框提供空状态引导。
- 设置窗口采用固定 Header/Footer 与内容滚动布局。
- 设置变更即时生效并持久化。

## 默认快捷键

- 立即排版：`Ctrl/Cmd + Enter`
- 复制结果：`Ctrl/Cmd + Shift + C`
- 打开设置：`Ctrl/Cmd + ,`

## 已知限制

- Markdown 保护是保守扫描器，不等同于完整 CommonMark/HTML 解析器。
- 单位识别使用有限词典，不覆盖完整计量单位语法。
- Unicode 等价规范化默认关闭，不会擅自使用 NFKC 改写原文。
- Span/TextEdit 迁移、长文本性能优化和真实 Tauri E2E 仍在后续路线图中。
- TUI 目前为实验性功能。
- Windows 版本为便携版，需要 WebView2 Evergreen Runtime。
- 当前不支持 macOS。
