# CopyPolish v0.6.0

CopyPolish v0.6.0 是一次面向中文文本清洗、工作流配置、桌面交互和终端体验的重要正式版本更新。完整变更列表以 [CHANGELOG.md](https://github.com/15699122/CopyPolish/blob/master/CHANGELOG.md) 为准。

## 新功能

### 来源文本清洗

- 方括号/中文方括号引用角标清理、连续 ASCII 空格折叠、连续空行限制。
- 新增默认关闭的高风险规则：数值标点异常空格（`spacing.numeric-punctuation`）、康熙部首兼容字符修复（`cleanup.kangxi-radicals`）、全角 ASCII 映射（`text.halfwidth-ascii`）与 CJK 内部单空格保守清理（`cleanup.cjk-internal-space`）。
- 清洗规则默认关闭，并通过结构保护跳过 URL、代码、公式和 Markdown 链接。

### 工作流预设

- 内置「中文文案」「PDF 清洗」「技术文档」预设，只处理粘贴文本；不解析 PDF/DOCX 文件本体，PDF 多栏顺序与段内软换行仍不处理。

### 自定义替换

- 支持字面量替换：有序执行、可启停、GUI 与 TUI 均可管理并持久化；不支持正则表达式，尽可能保护 Markdown、代码、URL 和公式。

### 输出与布局

- 实时/手动输出模式，自动/左右/上下布局，输入输出 Unicode 字符统计，复制结果与「复制并清空」（复制失败不会清空输入）。

### 设置体验

- `rules.yaml` 路径查看与复制、主题布局统一、规则悬停示例（示例与真实引擎输出由 Rust 测试强制一致）、键盘可访问、应用数据目录回退，以及设置损坏时的备份恢复。

### 帮助与首次引导

- 静态帮助入口与首次使用提示；帮助说明高风险清洗规则、结构保护、输出/复制动作及浏览器演示模式边界。

## TUI（Beta）

- GUI 与 TUI 共用 Rust 引擎；TUI 支持替换与转换请求面板、工作流预设、stdin/stdout 与文件模式、多行视觉换行、Unicode/emoji grapheme、OSC 52 剪贴板与设置共享。**TUI 仍为 Beta。**

## 简繁转换说明

- 已实现 `simplified-trad-conversion` 可选 feature（基于 `opencc-fmmseg`，只改写可编辑区间并保护链接/代码/公式）。
- **正式发布的默认构建不启用真实 T2S/S2T 转换**：设置界面会显示简繁选项，但默认构建禁用不可用选项并将选择归一化为 `none`，不会静默承诺转换。feature 构建仅用于专项验证，不作为标准正式资产。

## 安全与隐私

- 移除仓库内的本地环境路径、主机信息和凭据文件；实际凭据不再被 Git 跟踪，提供 example 模板并强化 security check。
- 历史分支与 tag 已重写；GitHub 上的 `refs/pull/*` 引用可能仍保留旧对象。

## 下载

| 平台 | 资产 |
| --- | --- |
| Windows GUI（便携） | `CopyPolish.exe`、`CopyPolish-windows-x64.7z` |
| Windows TUI | `CopyPolish-tui-windows-x64.7z` |
| Linux GUI | `CopyPolish_linux_amd64.deb`、`CopyPolish-linux-x86_64.rpm`、`CopyPolish_linux_amd64.AppImage` |
| Linux TUI | `CopyPolish-tui-linux-x86_64.7z` |
| 校验 | `SHA256SUMS` |

两个 Windows `.7z` 与 Linux TUI `.7z` 均在 staging 目录内部压缩，根目录直接包含可执行文件。校验方式：

```bash
sha256sum -c SHA256SUMS
```

## 升级说明

- 旧 `rules.yaml` 可继续使用；缺少新字段时自动回退默认值，stable rule keys 保持兼容。
- 程序目录设置不可写时自动回退应用数据目录。
- 建议重要文本首次使用新版本时人工复核输出。

## 已知限制

- 默认构建不启用真实简繁转换（见上文）。
- CJK 内部空格清理为未经真实语料验收的保守试实现；段内软换行与 PDF 多栏顺序不处理。
- Markdown 保护不是完整 CommonMark parser。
- TUI 为 Beta；SSH/OSC 52 行为取决于终端。
- Windows 需要 WebView2 Runtime。
- E2E 浏览器工具仍有已审阅的 WebdriverIO 传递依赖告警（见 `docs/decisions/wdio-transitive-dependencies.md`）。
