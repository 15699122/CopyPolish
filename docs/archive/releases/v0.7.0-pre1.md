# CopyPolish v0.7.0-pre1

> 当前状态：**预发布候选，尚未发布**。本文件为 `v0.7.0-pre1` 的发布说明，
> 供 GitHub Release workflow 的 `--notes-file` 使用。预发布按
> [manual-release.md §4](../../release/manual-release.md) 标记为 **pre-release**，
> **不占用 latest**；`v0.6.2` 仍是 latest。

## 范围

v0.7.0 的首个预发布版本，主题是 **GUI 中文化布局**、依赖维护与发布链路加固。
本预发布不新增排版规则，也不改变现有规则的默认行为。

## 主要变更

### GUI 中文布局与排版

- 主界面重排为「原始文本 → 排版结果」双区结构：宽窗口左右对照，窄窗口自动上下堆叠，
  并保留显式的布局选择。
- 顶部提供输出模式（实时 / 手动）与布局切换；手动模式提供「立即排版」动作，
  复用既有排版路径。
- 设置窗口由长列表改为**六个分类导航**：排版规则、替换与转换、编辑与输出、
  外观显示、快捷键、隐私与存储。
- 修正模式文案不一致（不再固定宣称「实时显示规范化结果」），复制反馈改为明确的状态切换。
- 新增统一的中文排版令牌（标题 / 副标题 / 说明 / 统计的字号与行距），
  并补全中文字体回退（PingFang SC / 微软雅黑 / Noto Sans CJK SC），**不引入在线字体**。

### 修复

- 设置分类化后，非规则分类不再显示会误改排版规则的「恢复默认」（改为仅在规则分类显示
  「恢复默认规则」）。
- GUI E2E 新增设置分类切换辅助，确保跨分类控件在挂载后再被访问，修复
  `selection-and-persistence`、`restart-settings`、`gui-visual-artifacts`、
  `simplified-trad-conversion` 的回归。

### 依赖与供应链

- Tauri：`@tauri-apps/cli` 2.11.4 → 2.11.5，Rust `tauri` 2.11.5 → 2.11.6。
- 前端：`lucide-react` 1.48.0、`jsdom` 30.1.1、`tailwind-merge` 3.7.0、
  `@types/node` 26.6.2；`opencc-fmmseg` 0.12.0 → 0.12.1。
- E2E 工具链：`undici`（6.x / 7.x 两条依赖线）、`brace-expansion`（1.x / 2.x）、
  `ip-address` 使用**同 major 版本区间**的 overrides 升级到修复版本，
  E2E 审计 advisory 从 16 个降为 2 个。
- CI/Release Actions：`checkout` v7.0.1、`setup-node` v7.0.0、
  `upload-artifact` v7.0.1、`download-artifact` v8.0.1。

### 验证入口

- 新增 `python3 scripts/verify.py --profile feature`，覆盖此前无常规 CI 覆盖的
  `simplified-trad-conversion` 可选 feature（clippy、测试与 TUI 构建）。

## 简繁转换构建能力

`t2s` / `s2t` 转换由 `simplified-trad-conversion` 可选 feature 提供，
**默认发布构建不静默承诺该能力**。本预发布的发布资产沿用既有 feature 配置，
未擅自改变。决策背景见
[decisions/simplified-trad-capability.md](../../decisions/simplified-trad-capability.md)。

## 已知限制

- **Windows 原生验证尚未完成**。GUI 中文布局的 WebView2 渲染、原生 DPI（80%–125% 缩放）、
  窗口控制与真实剪贴板，以及本候选资产的启动 smoke，仍为
  `WINDOWS_VERIFICATION_PENDING`，见 [validation/windows.md §4](../../validation/windows.md) Q3–Q8。
- 因此本预发布**不应被视为经过完整跨平台验收的正式版本**。

## 残余安全风险（限期接受）

- E2E 工具链 `extract-zip@2.0.1`：`GHSA-jmr9-qjv8-65gv` 与 `GHSA-7pqw-9j4j-h8q3`。
  该版本已是 npm 当前 latest，两个 advisory 均无 patched version，唯一自动修复是破坏性的
  WebdriverIO 8 降级。范围限于 E2E 工具链，**不进入生产应用与发布资产**；
  复核期限 **2026-10-06**，见
  [decisions/e2e-audit-policy.json](../../decisions/e2e-audit-policy.json)。
- Rust `glib 0.18.5`（`GHSA-wrw7-89jp-8q8g`）：仅影响 Linux GUI 资产的 GTK 依赖链，
  修复版本需 GTK 0.20 代际迁移；复核期限 **2026-12-31**，见
  [decisions/glib-0.18-soundness-risk.md](../../decisions/glib-0.18-soundness-risk.md)。
