# CopyPolish v0.6.2

> 当前状态：已于 **2026-09-07** 正式发布。

## 范围

v0.6.2 是隐私、安全、依赖和供应链维护版本，不新增用户功能、不新增排版规则，也不改变现有规则默认行为。

## 维护内容

- 强化用户正文不落盘、设置存储、IPC 稳定错误协议和资源边界的安全验证。
- 固定 GitHub Actions SHA，收紧 CI 权限，并接入 SBOM、license、checksum 和 Release 资产校验。
- 将 `ratatui` 升级至 0.30.2、`crossterm` 升级至 0.29.0，锁定 `lru` 0.18.4，处理对应 Dependabot low 告警。
- 记录 `glib 0.18.5` 与 E2E `extract-zip` 风险接受及复核期限。
- 完成 Windows 原生平台验证记录，覆盖 GUI、TUI、MSVC、WebView2、设置安全、Windows Terminal 和发布前 smoke。

## 供应链与发布说明

- E2E 工具链中的 `extract-zip` 告警仅存在于测试依赖，不进入生产 Release；风险登记复核日期为 2026-10-06。
- `glib 0.18.5` 修复版本需要 GTK 0.20/Tauri-Wry 代际迁移，当前按限期风险接受处理，复核日期为 2026-12-31。
- 发布资产必须包含七项平台资产、`SHA256SUMS` 和 `sbom.json`，并通过统一资产校验。

## 验证状态

- `dev` 与 `master` CI、CodeQL、依赖审计和本地 audit 门禁已通过。
- Windows 平台验证已由维护者于 2026-09-07 确认完成；未在此处虚构机器版本、测试计数或 artifact 路径。
- 已通过 `publish=false` 演练、资产校验和维护者批准，并创建 `v0.6.2` tag 和 GitHub Release。
